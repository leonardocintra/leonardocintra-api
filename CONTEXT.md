# Leonardo Cintra API

Esta API automatiza fluxos operacionais do Leonardo Cintra, incluindo a preparação de conteúdo para publicação por afiliados.

## Afiliados

**Mensagem de oferta**:
Conteúdo destinado a apresentar uma oferta de produto em grupos de WhatsApp ou Telegram, preservando as informações verificáveis fornecidas na entrada.
_Avoid_: anúncio, descrição de catálogo

**Melhoria de mensagem**:
Transformação de uma mensagem de oferta em uma versão mais curta, natural e persuasiva, sem inventar ou alterar informações da oferta.
_Avoid_: geração de oferta, reescrita livre
